# System Design: Learning from Scratch

A personal learning repository for system design — built hands-on, one topic at a time, in conversation with Claude Code.

---

## Who this is for

This repo belongs to **Raj** — a platform engineer with two years of professional experience. Raj has solid software engineering skills but is approaching system design formally for the first time: no prior courses, no textbooks, just learning by doing.

---

## Why this repository exists

Two reasons:

1. **Curiosity** — Understanding how large-scale systems actually work, especially in a world increasingly shaped by AI infrastructure.
2. **Interview readiness** — Building enough confidence and fluency in system design to hold my own in any engineering interview.

---

## How this works

Learning happens through conversation with Claude Code. Each concept gets:

- Its own **folder** (e.g., `01-networking/`, `02-databases/`, `03-caching/`)
- One or more **markdown files** inside that folder covering the concept, trade-offs, diagrams, and examples
- Incremental depth — simple definitions first, then real-world application

The philosophy is **hand-holding is fine**. There are no dumb questions here. Every term gets explained, every assumption gets challenged, and every concept gets tied back to something concrete.

## Ground rules

- Every topic starts from first principles — no assumed knowledge.
- Markdown files are the primary artifact: readable, version-controlled, and searchable.
- Real examples beat abstract theory. Where possible, concepts are tied to systems Raj has encountered or could encounter as a platform engineer.
- This is a living document. Old notes get updated as understanding deepens.
